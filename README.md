# Ludeo for Mac

Play game moments from the cloud, on your Mac.

**Download:** [latest release](https://github.com/ludeo-labs/osx-player/releases/latest) → `Ludeo-<version>.dmg`. Open it and drag Ludeo into Applications. Needs macOS 14 or later, Apple Silicon or Intel.

Builds are signed with Ludeo's Developer ID and notarized by Apple, and the app updates itself (Sparkle). Each release also carries the `appcast.xml` update feed.

This repository only holds releases; the app's source is private. Ludeo is also on the App Store and TestFlight for Mac, iPhone, iPad and Apple TV.
